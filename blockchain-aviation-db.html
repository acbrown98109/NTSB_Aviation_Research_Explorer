How AviChain Works

Coin Minting — When you look up an N-number, a genesis block is hashed using SHA-256 from the FAA registration data. This hash becomes the coin's unique identifier, immutably tying it to the real FAA record.

Block Chaining — Every subsequent event (ownership transfer, NTSB accident report, pilot link) is recorded as a new block. Each block stores: its own SHA-256 hash of its data, the previous block's hash (creating the chain), the FAA or NTSB source data, and a timestamp.

Data Sources

  • FAA Aircraft Registry API — registry.faa.gov/api/ — N-number registration, owner, make/model, airworthiness class
  • NTSB CAROL API — data.ntsb.gov/carol-main-public/api/ — Accident/incident reports cross-referenced by N-number
  • FAA Airmen Inquiry API — amsrvs.registry.faa.gov/airmeninquiry/ — Pilot certificates, ratings, medical class
  • FAA RelayFlight — Registry history endpoints for prior owners
  • OpenSky Network — opensky-network.org/api/flights/aircraft — Public ADS-B flight history by ICAO24 Mode-S hex, 30-day rolling window; used to compute block time / operating hours from closed flight plans
  • ADS-B Exchange — globe.adsbexchange.com/re-api/ — Live ADS-B position data by N-number registration

Maintenance Records — Public Record — Maintenance data is fetched from three FAA public sources and recorded as plaintext blocks on the chain, identical to ownership and accident data:

  • FAA SDR Database — av-info.faa.gov/sdrx/ — Service Difficulty Reports filed by operators and mechanics
  • FAA Form 337 — av-info.faa.gov/ — Major Repair & Alteration records filed per 14 CFR Part 43; publicly archived by FAA
  • FAA AD Library — rgl.faa.gov/ — Airworthiness Directives published in the Federal Register; compliance is mandatory and traceable
Manual logbook entries (14 CFR §91.417) can also be appended as blocks — stored plaintext, no encryption, same as all other public record fields.

Cryptographic Integrity — SHA-256 block hashing via the browser's SubtleCrypto API links every block to the one before it. No data is encrypted or obscured — hashing is used solely for tamper-detection, not privacy. The full chain and Merkle root are verifiable client-side.

Flight Plans & Operating Hours — Each aircraft's N-number is converted to its ICAO24 Mode-S hex code using the FAA sequential allocation algorithm. Closed flight plans from the OpenSky Network (30-day rolling ADS-B window) are recorded as flightlog blocks — departure airport, arrival airport, block-off / block-on timestamps, and computed block time. A summary hourslog block accumulates total operating hours for the coin. All flight data is public ADS-B; no encryption applied.

Autonomous Public Record — AviChain is a self-updating, ownerless immutable record. No individual owns a coin or controls its chain. Every block is appended automatically from public federal APIs whenever an N-number is queried. The chain grows as public records grow — new accidents, new ownership transfers, new maintenance filings, new flight hours — without any user needing to sign or authorize updates. The record is the public record.

Public Record Notice — All data is sourced from U.S. federal public record databases. Aircraft registration (14 CFR Part 47), accident reports (49 U.S.C. §1131), airmen records, maintenance entries (14 CFR §91.417 / Part 43), Form 337s, SDRs, and ADs are public information. No data is encrypted.
