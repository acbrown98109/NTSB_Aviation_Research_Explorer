How AviChain Works

Coin Minting — When you look up an N-number, a genesis block is hashed using SHA-256 from the FAA registration data. This hash becomes the coin's unique identifier, immutably tying it to the real FAA record.

Block Chaining — Every subsequent event (ownership transfer, NTSB accident report, pilot link) is recorded as a new block. Each block stores: its own SHA-256 hash of its data, the previous block's hash (creating the chain), the FAA or NTSB source data, and a timestamp.

Data Sources

  • FAA Aircraft Registry API — registry.faa.gov/api/ — N-number registration, owner, make/model, airworthiness class
  • NTSB CAROL API — data.ntsb.gov/carol-main-public/api/ — Accident/incident reports cross-referenced by N-number
  • FAA Airmen Inquiry API — amsrvs.registry.faa.gov/airmeninquiry/ — Pilot certificates, ratings, medical class
  • FAA RelayFlight — Registry history endpoints for prior owners

Cryptographic Integrity — All hashes use the Web Crypto API (SubtleCrypto SHA-256) running entirely in your browser. No data is sent to any third-party server. The chain is verifiable client-side.

Public Record Notice — All data displayed is sourced from U.S. federal public records databases maintained by the FAA and NTSB under public record law. Aircraft registration (14 CFR Part 47), accident reports (49 U.S.C. § 1131), and airmen records are public information.
